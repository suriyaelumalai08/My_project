# Main Files Description

## 1. LINEAR_regression.ipynb

## 3. TASK - ML MODEL 1.ipynb

Machine Learning model training and prediction experiments.

Demonstrates training datasets, sampling methods, and splitting data.

Symbolic mathematics using SymPy.

Simple Text-to-Speech application built using Python.

# Installation

## Clone the Repository

```bash
git clone https://github.com/suriyaelumalai08/My_project.git
```

## Move into the Project Folder

```bash
cd My_project
```

## Install Required Libraries

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

---

# Running Jupyter Notebooks

Start Jupyter Notebook:

```bash
jupyter notebook
```

Then open any `.ipynb` file.

---

# Running the Text-to-Speech App

Move into the folder:

```bash
cd tts-app
```

Run:

```bash
python main.py
```
